# Pitch textures

`grass-*.jpg` are [Grass 005](https://ambientcg.com/view?id=Grass005) from ambientCG, licensed
CC0 1.0 (public domain): the colour, OpenGL normal and roughness maps, recompressed. They're the
same files the football quiz's shootout uses. The pitch tiles them every 2.5 m over its drawn
stripes and markings, for the detail of the grass up close.
